# CLAUDE.md

This repository uses `AGENTS.md` as the canonical source of engineering conventions.

When working in this repository:

1. Follow the repository-wide instructions defined in `/AGENTS.md`.
2. Follow the closest local `AGENTS.md` for the current application or package.
3. Local instructions extend repository-wide conventions and should not contradict them.

If no local `AGENTS.md` exists, follow the repository-wide instructions.
