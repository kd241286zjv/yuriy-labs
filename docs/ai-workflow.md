# AI-Assisted Development Workflow

## Purpose

This repository treats AI as an engineering assistant rather than an autonomous developer.

AI tools accelerate implementation, documentation and refactoring while architectural decisions remain the responsibility of the developer.

---

## AI Tools

Current workflow may involve:

- ChatGPT
- Codex
- GitHub Copilot
- Claude Code

Additional tools may be adopted as the project evolves.

---

## Responsibilities

### ChatGPT

Used for:

- architecture discussions;
- engineering decisions;
- feature planning;
- code reviews;
- documentation;
- technology evaluation.

---

### Codex

Used for:

- implementing features;
- refactoring existing code;
- generating boilerplate;
- updating documentation;
- repetitive engineering tasks.

---

### GitHub Copilot

Used for:

- inline code completion;
- small code suggestions;
- repetitive code generation.

---

### Claude Code

May be used for:

- repository-wide refactoring;
- multi-file modifications;
- documentation updates.

---

## Engineering Workflow

A typical development cycle:

1. Discuss architecture.
2. Define implementation plan.
3. Update documentation if necessary.
4. Implement incrementally.
5. Review generated code.
6. Commit small logical changes.

---

## AI Code Review

AI-generated code should always be reviewed before committing.

Review should verify:

- readability;
- maintainability;
- consistency;
- architectural correctness;
- unnecessary complexity.

---

## Documentation

Whenever architectural decisions change:

- update `AGENTS.md`;
- update local `AGENTS.md`;
- update documentation if required.

Documentation should evolve together with the implementation.
